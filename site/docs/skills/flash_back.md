# 回溯 · FlashBack

<span class="bs-tag" style="color:#FFFF55;border-color:#FFFF55">稀世</span> · 最高 **Lv.3** · 内部 ID <code>flash_back</code>

> 右击在原地记录状态，一段时间后闪回到该位置与状态（冷却时间: 360秒）

## 使用条件

- **适用物品**：剑、斧、弓、弩、三叉戟
- **砂轮可移除**：是

## 参数

| 参数 | 取值 |
| --- | --- |
| 音效 <code>sound</code> | `ENTITY_ENDERMAN_TELEPORT` |
| 冷却（秒） <code>cooldown</code> | `360` |
| 粒子效果 <code>particle</code> | `{"type": "CRIT", "amount": 2}` |
| 持续时间（刻） <code>duration</code> | `200-level*20` |
