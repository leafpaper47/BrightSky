# 诅咒附魔（9 个）

NereusOpus 的负面附魔，会给持有者带来惩罚，只能靠砂轮或祛魔手段清除。

| 附魔 | 最高等级 | 适用物品 | 效果 |
| --- | --- | --- | --- |
| **仇恶诅咒**<br><code>calling_curse</code> | 1 | 头盔、胸甲、护腿、靴子 | 使装备被穿戴时会激怒周围的怪物 |
| **无力诅咒**<br><code>breaklessness_curse</code> | 3 | 镐、斧、锄、铲 | 使工具破坏方块时有概率失败 |
| **火焰诅咒**<br><code>inaccuracy_curse</code> | 3 | 弓 | 使弓射出的箭将错误地燃烧对象 |
| **烙印诅咒**<br><code>permanence_curse</code> | 1 | 所有物品 | 使物品在铁砧中无法被修改 |
| **脆弱诅咒**<br><code>fragility_curse</code> | 3 | 所有物品 | 使物品被使用时额外扣除耐久度 |
| **腐烂诅咒**<br><code>decay_curse</code> | 3 | 所有物品 | 处于非手持状态时耐久度持续降低 |
| **软弱诅咒**<br><code>harmlessness_curse</code> | 3 | 剑、斧 | 使剑或斧的攻击有概率无效 |
| **霉运诅咒**<br><code>misfortune_curse</code> | 3 | 镐、斧、锄、铲 | 使工具破坏方块时有概率不掉落 |
| **饥饿诅咒**<br><code>hunger_curse</code> | 1 | 头盔 | 使佩戴该头盔时饥饿速度加快 |
