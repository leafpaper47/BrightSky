> 近战攻击时有概率使对手流血

## 基本信息

| 项目 | 内容 |
| --- | --- |
| 适用物品 | 三叉戟 |
| 冲突附魔组 | 持续类附魔、概率类附魔 |
| 互斥附魔 | — |
| 每级效果预览 | `&7近战攻击时有&a{概率}&7的概率使对手流血 (伤害:&a{每次伤害}&7/&a{间隔} &7持续&a{持续时间}&7)` |

| 属性 | 单位 | 表达式 / 取值 |

| 概率 | % | `8*{level}` |

| 每次伤害 | 点 | `0.5*{level}` |

> [!note] 表达式说明
