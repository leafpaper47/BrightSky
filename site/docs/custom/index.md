# 自定义附魔（15 个）

Aiyatsbus 内置的非原版附魔，机制由 Fluxon 脚本驱动，可组合出原版没有的战斗效果。

### [再植](/custom/replanter.md)

<span class="bs-tag" style="color:#66c18c;border-color:#66c18c">罕见</span> · 最高 **Lv.1** · 适用：靴子

踩坏耕地时，只会使作物退化而不是掉落

### [弹跳鞋](/custom/jelly_legs.md)

<span class="bs-tag" style="color:#63bbd0;border-color:#63bbd0">精良</span> · 最高 **Lv.1** · 适用：靴子

摔伤时可减少伤害并弹起

### [剑气](/custom/sword_beam.md)

<span class="bs-tag" style="color:#eb507e;border-color:#eb507e">史诗</span> · 最高 **Lv.3** · 适用：剑

### [推进器](/custom/propulsion.md)

### [棘盾](/custom/barb.md)

### [蓄能](/custom/accumulating.md)

### [匠心](/custom/artisanship.md)
